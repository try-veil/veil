📋 How This Works

  1. Generate Token: Run bun generate-token.js 1 test@example.com
  2. Paste Token: Enter the token above and click "Create Payment Order"
  3. API Call: Page automatically calls POST /api/v1/payments/create
  4. Fresh Order: A new Razorpay order is created each time
  5. Pay: Click "Pay Now" and use test card 4111 1111 1111 1111
  6. Webhook: Razorpay sends webhook to your app automatically
  7. Verify: Check PAX logs and ngrok interface

🔍 Where to Look

  • PAX Service Terminal: Look for webhook processing messages
  • ngrok Terminal: Look for POST requests to /api/v1/webhooks/razorpay
  • ngrok Web UI: http://127.0.0.1:4040 - see full request/response
